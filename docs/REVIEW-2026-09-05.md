# ギター練習帖：現状レビューと今回の改善

基準：`main` の `e27b48170d251fcca167609a8557686250bbc63e`。
基礎3課、フレーズ5件、統合リズム12パターンを対象に、コード・教材・既存テストを確認しました。

## 評価

静的配信、教材JSONの分離、オーディオクロックでの先読み再生、実音サンプル、オフライン対応は揃っています。VexFlowによる五線譜とTAB、連符・特殊奏法のデータ検証も維持されています。

練習体験で不足していたのは、8小節を短い区間に分ける操作、譜面・お手本の補助を減らす操作、練習条件付きの振り返りです。今回はこの3点を一つの流れとして実装しました。

## 発見した不具合と修正

| 優先度 | 発見事項 | 修正 |
|---|---|---|
| 高 | `phrase.js` の停止はマスター音量を一時的に下げ、120ms後に戻していました。長い音や予約済みのストロークが復活する余地があります。 | サンプルと合成音の発音ノードを追跡し、停止時に予約を含めて停止・切断。単音確認と伴奏プレビューも対象にしました。 |
| 高 | 音源の読み込みを待つ再生要求に取消確認がなく、停止・フレーズ変更後に古い要求が再生を始める可能性がありました。 | 要求世代を照合して古い要求を破棄し、読み込み中にも停止できるようにしました。 |
| 高 | データ検証は32分音符や5連符を受け付けますが、再生は1拍12tickで整数化できる音価に限られていました。 | `core/practice.js` で音符の拍位置からイベントを構成し、その時刻をオーディオクロックへ予約します。 |
| 中 | 初期教材の取得とイベント登録が完了する前に、ページ読み込み完了後の操作が到着する競合がありました。 | 再生操作を教材取得より先に登録し、再生要求が教材の準備を待つようにしました。記録読み込みも再生操作の初期化から分離しました。 |

## 実装した練習機能

| 機能 | 動作 |
|---|---|
| 小節区間練習 | 開始・終了小節、1小節／2小節／全体、前後の区間へ移動。ループは選択区間に限定。伴奏のコード位置も同じ区間に合わせます。 |
| 予備拍 | なし／1小節／2小節。反復開始前にオーディオクロック基準で鳴らします。 |
| 補助表示 | 全表示、音名なし、五線譜のみ、暗譜。暗譜ではお手本メロディもOFFにし、独立して再指定できます。 |
| お手本のON/OFF | メロディを消して伴奏に合わせて演奏できます。 |
| 練習記録 | 再生条件、区間の再生完了回数、経過時間と、本人の「弾けた／要復習」を保存します。 |
| 次回への目安 | 同じテンポ・区間・補助・伴奏条件での記録を比較し、再確認や次の区間を案内します。 |
| 継続・バックアップ | フレーズ別の設定を復元。IndexedDBへ記録を保存し、全フレーズのJSON書き出し・検証付き追加読み込みに対応します。 |

## 実装時に判断した仕様

- 初期状態は従来どおり全体再生・予備拍なし。区間や予備拍を選んだ後は設定を保存します。
- 予備拍は開始時に一度だけ鳴らします。反復の間には挿入せず、拍のつながりを維持します。
- 区間の入口がタイの後半なら、その入口で改めて発音します。タイの持続時間は選択区間の出口で区切ります。
- テンポ・区間・補助・伴奏・ループの変更は停止してから適用します。記録には再生開始時の条件を保存し、停止後の変更と混ぜません。
- 自己評価の達成は `assessment.status = provisional`、`basis = reported` とします。再生完了を本人の演奏成功として扱いません。録音・自動採点・自動昇級は実装していません。
- 2回の達成記録は次回の再確認を促す目安です。反復再生の回数をそのまま複数の成功申告へ変換しません。
- バックアップは今回追加したフレーズ記録が対象です。基礎画面のチェック記録は移行・上書きしません。輸入した測定値や合否を信用せず、自己評価から再構成します。
- 保存失敗時は未保存の結果を保持して再試行できます。取り込みは全件検証後に単一トランザクションで追加し、同じIDの既存記録を優先します。
- バックグラウンド移行時は停止します。予約が250ms以上遅れた場合も停止し、過去の音をまとめて鳴らすことを避けます。
- ビルド工程・実行時npm依存は追加していません。新しい2モジュールはService Workerの対象へ登録し、キャッシュをv13に更新しました。

## 次に優先したい機能

| 順序 | 機能 | 理由・現在の範囲 |
|---|---|---|
| 1 | 録音・再生しての振り返り | 音量差、不要弦の鳴り、運指による音色差を自分で確認する手段になります。保存容量と録音入力の扱いを設計する必要があります。 |
| 2 | 五線譜と指板の対応練習 | 調号を含む音の位置と、複数の弦上の候補を練習する独立ドリル。既存の一音表示を発展させる余地があります。 |
| 3 | エレキ音色と奏法再生の拡充 | 現在の旋律音源はナイロンギターです。H/P・スライド・ビブラートの記号表示と、それぞれの音響再現は別の実装課題として残ります。 |
| 4 | 休符・複声部・フレーズの変拍子 | 現在のフレーズ検証と伴奏は4/4・単旋律です。休符、低音と旋律の独立した持続を表現するには教材スキーマと描画・再生を揃えて拡張する必要があります。 |
| 5 | 教材の段階拡充と共通時計の整理 | 基礎は3課、フレーズは5件です。設計文書の大部分は将来構想であり、`core/clock.js` の共通化、測定・処方エンジンは未実装です。 |
